This topic explains how to implement editions in new runtimes and generators.
Overview Edition 2023 The first edition released is Edition 2023, which is designed to unify proto2 and proto3 syntax. The features we’ve added to cover the difference in behaviors are detailed in Feature Settings for Editions.
Feature Definition In addition to supporting editions and the global features we’ve defined, you may want to define your own features to leverage the infrastructure.

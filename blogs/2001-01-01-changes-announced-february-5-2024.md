This topic covers breaking changes in Java, C++, and Python in the 26.x line. JSON Formatter Option Changes Starting in the 26.x line, the JSON formatter option to print default-valued fields is replaced with a fixed way to handle proto2 and proto3 optional fields consistently. Java: includingDefaultValueFields() is replaced with alwaysPrintFieldsWithNoPresence().

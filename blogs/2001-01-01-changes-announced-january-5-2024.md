This topic covers breaking changes in Ruby and Python in the 26.x line. Ruby Breaking Changes Freeze Is Now Recursive in Ruby Starting in the 26.x line, when freeze is applied it will be applied recursively, affecting all sub-messages, maps, and repeated fields. Python Breaking Changes Removing Deprecated APIs In the 26.x release, the following deprecated APIs will be removed: AddFileDescriptor AddDescriptor AddEnumDescriptor AddExtensionDescriptor AddServiceDescriptor Rejecting Extend Repeated Field with None Iterable Starting in the 26.

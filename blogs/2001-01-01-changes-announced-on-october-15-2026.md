The following sections cover additional planned breaking changes in the v38 release, expected in 2027 Q1. These describe changes as we anticipate them being implemented, but due to the flexible nature of software some of these changes may not land or may vary from how they are described in this topic. Changes in C++ Remove NULL Termination in Descriptor Names Descriptor APIs that return absl::string_view will no longer guarantee null termination.
